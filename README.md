# Next Level Gaming & Esports Arena — XHAW5112

A responsive HTML/CSS/JavaScript website starter based on Scenario 3: Gaming & Esports Arena.

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension if needed.
3. Open `index.html`, right-click in the editor and select **Open with Live Server**.
4. Use the navigation menu to test every page.

You can also open `index.html` directly in a browser, although Live Server is recommended.

## Booking discounts
- 1 distinct selected offering: 0%
- 2 distinct selected offerings: 5%
- 3 distinct selected offerings: 10%
- 4 or more distinct selected offerings: 15%

The calculator uses the supplied scenario prices. It is a front-end estimate only; it does not create a real reservation or accept payment.
